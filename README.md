# Linen Leaf Launch

Build the site shell and homepage for Linen & Leaf Dry Cleaners, an independent dry-cleaning and laundry service launching in Sarojini Nagar, New Delhi.

BRAND
- Name: Linen & Leaf Dry Cleaners
- Positioning: premium but approachable, eco-conscious, technology-forward, warm and trustworthy — deliberately not a generic laundry-app look
- Colour: deep teal-green as the primary ink/accent colour, warm cream/ivory background, a small warm gold or brass accent used sparingly (e.g. on the wordmark's ampersand or CTA highlights). Flat and refined — no gradients, no neon.
- Typography: elegant, warm serif or refined sans-serif — boutique feel, not tech-startup generic
- Logo: build a text-only wordmark logo — "Linen & Leaf" — no icon, no leaf illustration, no separate graphic symbol. The ampersand can carry some personality/flourish. Use this wordmark in the header and footer.

CONTACT / LOCATION
- Address: 1st Floor, Shop No. 108, Sarojini Nagar Market, New Delhi 110023
- WhatsApp (primary): +91 88004 46635 — use this for all WhatsApp click-to-chat buttons, formatted as https://wa.me/918800446635
- Secondary phone: +91 98186 61308

SITE STRUCTURE
Set up navigation and routing for these pages (stub/placeholder is fine for now except Home, which should be fully built): Home, Services & Pricing, How It Works, Technology & Process, Service Area, About, Book a Pickup / Contact, FAQ.

HOMEPAGE — build this fully
- Hero section: a strong headline built around the core promise (dry cleaning that uses 99% less water than a conventional wash, fully tracked, fast), a subheadline, and a primary CTA button ("Book a Pickup") plus a WhatsApp button
- USP highlights section: four cards/blocks for the core USPs — 99% less water, live order tracking, fast delivery, best-in-class equipment — plus room for 2–3 supporting USPs (garment care guarantee, transparent pricing, hygiene-first processing)
- "How it works" teaser: 4 steps — book a pickup (WhatsApp, call, or the form), we collect/tag/photograph your garments, cleaned on modern low-water equipment with live tracking, delivered back to your door
- Trust signals section: space for testimonials/reviews (placeholder content is fine, this business hasn't launched yet)
- Footer: wordmark, contact info (address, both numbers, WhatsApp link), links to other pages

TECHNICAL REQUIREMENTS
- Fully responsive: the layout must work cleanly at mobile (~375–428px), tablet (~768–1024px), and desktop (1280px+) — this is a hard requirement, not a nice-to-have
- No login, no database needed at this stage — this is a static informational build for now
- Clean, semantic HTML with meta tags ready for basic SEO (title, description) on the homepage

Please build the design system (colours, typography, spacing, reusable components like buttons/cards/nav) and the homepage first — I'll follow up with the remaining pages one at a time.
